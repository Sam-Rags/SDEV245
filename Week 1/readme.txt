Readme for Week 1 App submission

The CIA triad refers to the concepts of Confidentiality, Integrity & Availability. Together these three cornerstones ensure a program, app, webpage, etc meet the requirements of modern security standards.
Confidentiality means the data can only be accessed by those who are supposed to have access and no one else
Integrity means we are sure the data has gotten where it's going unaltered.
Availability means anyone who needs access to the data has it at any time

The simple web app I have created here is just a single page with a login form. The app will take valid credentials only (these can be found in the script.js file) and validate them against what the user has entered as well as the user's chosen role. If the combination is found to be valid the app logs in and displays content unique only to that user's role. If the logout button is clicked, all of that login content is hidden and the login flags are set to false again.
